Introduction

Welcome to APIEngine — the fastest way to go from database to production APIs.

New to APIEngine? Follow our Quick Start Guide to create your first workspace and generate APIs in under 5 minutes.

What is APIEngine?

APIEngine is a SaaS platform that lets you connect any database (or use our hosted service), automatically generate RESTful CRUD APIs for every table, deploy custom endpoints, and protect everything with built-in identity management.

Core Concepts

Workspaces

Isolated environments, each backed by a database. Think of them as projects.

Auto CRUD

Automatic REST endpoints generated from your database schema.

Custom APIs

Deploy your own endpoints with custom business logic.

Security

API keys, managed identity provider, or external IdP integration.

Quick Example

Here's what happens when you create a workspace with a database that has a users table:

// Auto-generated endpoints for "users" table
GET    /api/v1/users          // List all users
GET    /api/v1/users/:id      // Get user by ID
POST   /api/v1/users          // Create user
PUT    /api/v1/users/:id      // Update user
DELETE /api/v1/users/:id      // Delete user

That's it. No code, no configuration. Just connect and go.
