GET Top Customers Report /custom/top-customers
● Deployed

SQL Query

SELECT u.id, u.first_name || ' ' || u.last_name AS name, u.email, COUNT(o.id) AS total_orders, SUM(o.total) AS lifetime_value FROM users u JOIN orders o ON u.id = o.user_id WHERE o.created_at >= :start_date GROUP BY u.id, u.first_name, u.last_name, u.email ORDER BY lifetime_value DESC LIMIT :limit

Parameters

start_date date required
limit integer default: 10
